# Eoullim 어울림 — v3

한국에 온 외국인 유학생에게 **같은 나라 친구 3~4명 + 한국인 멘토 1명의 「우리 조」**를 만들어 주는 캠퍼스 앱 — 성균관대 HUSS AI BRIDGE 「AI 융합 커뮤니티」 2gether 팀.
그룹(라포 형성)은 무료, 수익은 **이벤트 참가비 수수료(메인)**와 **포인트(보조)**.

**데모: https://eoullim-skku.vercel.app** (소개: `#/about`) · 가입·로그인 없이 QR로 바로 쓴다.
v1(멘토 매칭, 2026-09-28)은 태그 `v1-demo`, v2(포인트 질문 게시판, 2026-09-30)는 git 기록에 있다.

## 기능

| 화면 | 무엇 |
|---|---|
| **소속 바** | 모든 화면 맨 위 — 「🏫 성균관대학교 › 커뮤니티 게시판 · 🇵🇭 필리핀 2조」 |
| **시작** | 학교 → 출신 나라 → 앱 언어 → 닉네임. 같은 학교·같은 나라 그룹에 자동 배정 (4명 차면 다음 조) |
| **내 그룹** (무료) | 그룹 채팅(실시간 번역) · 이번 주 그룹 미션 · 우리 조가 가는 이벤트. 3명이 모이면 「시작」 |
| **커뮤니티** | 질문·도움 요청(포인트 선택) · 같이 해요(일시적 모임) · 자유 · 언어별 라운지 · 인기 |
| **이벤트** (메인 수익) | 🇰🇷 한국 체험(사주·신당동 귀신 투어·한복) · 🌏 나라별 명절 · 🏆 그룹 대항. 참가비 결제(데모), 어울림 수수료 15%, 2일 전까지 무료 취소, 최소 인원 미달 시 자동 취소·환불 |
| **포인트** (보조 수익) | 100원 = 1P · 질문에 걸면 답이 빨라짐 · 72시간 무답변 환불 · 이벤트 결제 내역 |
| **멘토** | 초대 코드로만 켜진다. 그룹 맡기(최대 3개) · 이벤트 열기 · 한국식 질문 답변 · 신고 처리 · 수익 구조(수익의 30%를 멘토가 실적대로) |
| **언어** | 15개 언어. 영어·한국어는 직접 쓴 글, 나머지 메뉴는 기계 번역. 글·댓글·이벤트·채팅은 내 언어로 자동 번역 + 「원문 보기」 |

번역: 무료만 쓴다 — 휴대폰이 Google 무료 주소에 직접 요청 → 실패하면 서버(Google → MyMemory, 글·채팅만). 예시 글의 한국어·영어 번역은 `server/tr-seed.js`에 저장돼 있어 서비스가 막혀도 데모가 보인다 (`node scripts/seed-translations.mjs`로 다시 만든다).

개인정보: 이름·학번·연락처·위치를 받지 않는다. 나라는 그룹 배정에만 쓰고 글에는 보이지 않는다. 기기마다 무작위 코드(= 복구 코드)를 만들고 서버는 그 해시만 저장한다. 글 속 전화번호·이메일·메신저 ID는 서버에서 `***`로 가린다. 프로필은 기기에만 저장되고 글에는 닉네임·아바타만 붙는다.

정의 문서: DEAN `03_PROJECTS/AI융합커뮤니티/PRD_v2.md`.

## 구조

| 경로 | 무엇 |
|---|---|
| `src/` | React + Vite 화면 (해시 주소) |
| `api/rpc.js` | Vercel 함수 하나. `POST /api/rpc` `{ action, ... }` + 헤더 `x-device-key` |
| `server/logic.js` | 그룹·이벤트·결제·포인트·채택·환불·신고 규칙 (모든 계산은 서버에서). v2 DB는 `migrate()`가 v3로 올린다 |
| `server/translate.js` | 번역 (무료 서비스만, 키·결제 없음) |
| `server/store.js` | 비공개 Vercel Blob(서울 `icn1`)의 JSON 한 개. ETag 조건부 저장으로 동시에 써도 안 꼬인다 |
| `server/seed.js` | 예시 글·그룹 8개·이벤트 8개 (앱에 「예시」 표시, 시간 규칙 적용 안 함) |

저장 위치: 운영 `eoullim/db.json` · 미리보기 `eoullim/db-preview.json` · 로컬 `eoullim/db-dev.json` (`.env.local`의 `EOULLIM_DB`).

## 실행

```bash
npm install
npx vercel env pull .env.local   # BLOB_READ_WRITE_TOKEN
# .env.local에 ADMIN_CODE=… 와 EOULLIM_DB=eoullim/db-dev.json 추가
npm run dev                      # http://localhost:5173 (로컬에서도 /api/rpc가 돈다)
```

배포: `main`에 푸시하면 Vercel 프로젝트 `eoullim`이 자동 배포 → `eoullim-skku.vercel.app`. 환경 변수 `ADMIN_CODE`(관리자 초대 코드)와 `BLOB_READ_WRITE_TOKEN`이 Vercel에 있다.
유료 LLM·번역 API를 쓰지 않는다.
